# obsidian-papers

一个用 Obsidian 维护的**论文阅读库**：一篇论文一个文献笔记，一个方向一个主题笔记，
产出（综述 / 复现记录 / 汇报）落在 `03_输出`。

目标读者是刚开始做科研的本科生 —— 所以这里刻意保持**零插件**：只用 Obsidian 自带的
Bases 表格与核心模板，clone 下来打开就能用。

## 结构

```
首页.md              入口：当前方向、本周目标、流水线说明
00_收件箱/            只记一行：标题 + 为什么可能有用
01_文献/              一篇论文一个笔记；文献总表.base 是可筛选的表格视图
02_主题/              跨论文综合，画方法谱系
03_输出/              综述、复现记录、组会报告
99_模板/              文献 / 主题 / 周复盘 三个模板
问题清单.md           选题从这里长出来
pdfs/                 PDF 不放仓库，见 pdfs/README.md
```

## 约定

- 文件名：`年份 第一作者 - 短标题.md`，年份打头便于按时间排。
- 文献笔记的 frontmatter 固定字段：`title / authors / year / venue / doi / status / topics / rating / pdf`。
- `status` 取值：`待读` → `在读` → `精读` → `已复现`。
- 每条文献笔记必须回答 5 个问题，**第 5 问「和我研究的关系」写不出来，这篇就是白读**。

## 注意

- `pdfs/` 里的 PDF 因版权原因未入库，因此本仓库中文献笔记的 `pdf:` 链接是断的（预期行为）。
- 笔记内容会持续变化，是工作草稿，不建议直接引用。
