# 03_输出

**只有写出来的东西才算数。** 这个文件夹的增长速度，直接决定你的科研进度。

四类输出，按难度排序：

| 类型 | 篇幅 | 什么时候写 | 作用 |
| --- | --- | --- | --- |
| 组会 / 读书报告 | 1 页 | 每周 | 逼自己把话说清楚，让导师知道你在动 |
| 主题综述 | 3–5 页 | 每读 8–10 篇 | 你的第一篇"论文底稿" |
| 复现记录 | 不限 | 每次跑代码 | 环境、参数、结果差异、踩坑 —— 最有含金量的本科生产出 |
| 小论文 / 投稿 | — | 有结果之后 | 目标：会议短文、竞赛、大创结题 |

## 复现记录模板（最推荐先写这个）

```markdown
# 复现：<论文标题>

## 目标
原论文的哪个结论，我要验证什么

## 环境
GPU / 框架版本 / 代码来源（官方 or 第三方）

## 跑了什么
命令、参数、数据集

## 结果
我的数字 vs 论文数字（表格）

## 差异分析
差在哪，我猜为什么（超参？数据？实现细节？）

## 下一步
```

> 复现失败也是结果。"没跑通 + 定位到是 X 的原因" 比 "跑通了但不知道为什么" 值钱得多。
