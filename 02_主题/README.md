# 02_主题

**一个方向 = 一个文件。** 这里是整个库最值钱的地方 —— 文献笔记是"别人说了什么"，主题笔记是"我认为什么"。

## 什么时候开一个主题笔记

不是读完第一篇就开。**攒够 3–5 篇同方向论文之后再开**，否则你只是在复述别人的摘要。

## 一页主题笔记的结构

1. **这个方向在解决什么**（两句话，外行能听懂）
2. **方法谱系图**：把读过的论文按"思路"分组，而不是按时间列
3. **公认的硬骨头**：大家都知道但还没解决的事 —— 这就是选题矿脉
4. **我读过的 / 待读的**：链接列表 + 一句话评价
5. **我的判断**：哪条路我押注，为什么

## 命名

```
方向名.md            机械臂动态抓取.md
方向名 - 子问题.md    机械臂动态抓取 - 抓取位姿表示.md
```
