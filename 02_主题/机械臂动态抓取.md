# 机械臂动态抓取

> 一页纸说清：**目标会动的时候，机器人怎么"看见—想清—够到—抓住"**。
> 这是本库的第一个主题笔记，结构可以照抄到别的方向。

## 1. 这个方向在解决什么

机械臂要从一张图里找到目标、算出怎么抓、规划一条不撞的路径、再稳稳地够过去。
目标**静止**时这套东西已经比较成熟；目标**在动**时，每一环都会引入延迟和不确定性，误差会一路放大到"抓空"。

## 2. 方法谱系（按"思路"分组，不按时间）

```
           ┌─ 检测/分割：YOLO 系列、Mask R-CNN
  感知 ────┼─ 跟踪/预测：DeepSORT、ByteTrack、卡尔曼 / IMM / 学习式轨迹预测
           └─ 抓取位姿：GG-CNN（像素级）、GGCNN2、GraspNet（点云 6-DoF）、6-DoF GraspNet

  规划 ────┬─ 采样类：RRT、RRT*、APF-RRT*、BIT*
           ├─ 优化类：CHOMP、TrajOpt、GPMP2
           └─ 学习类：模仿学习 / 强化学习策略直接出轨迹

  控制 ────┬─ 经典：PID + 计算力矩、五次多项式插值
           ├─ 非线性：反步法（backstepping）、滑模
           └─ 学习式：视觉伺服 + 学习残差
```

## 3. 公认的硬骨头（选题矿脉）

- **延迟**：从拍到图到臂动，几十毫秒的延迟在快速目标上就是几厘米误差 —— 怎么补？
- **预测**：目标机动（突然变向、被遮挡）时，卡尔曼失效，学习式预测又缺数据
- **感知-规划耦合**：现在多是"先估位姿再规划"，位姿不确定性没有传下去
- **sim-to-real**：仿真里成功率 95%，实物掉到 60%，差在哪
- **抓取中的"抓"**：够到了但抓不稳（滑动检测、力控）
