# 01_文献

**一篇论文 = 一个笔记文件。** PDF 放 `pdfs/`，笔记放这里，用 frontmatter 的 `pdf:` 字段链接。

## 文件名

```
年份 第一作者 - 短标题.md
2026 李春辉 - 机械臂动态目标抓取.md
2021 Kalashnikov - MT-Opt 规模化抓取.md
```

年份打头 → 文件列表天然按时间排；短标题只为扫读，完整标题写在 `title:` 里。

## status 的四个值

| 值 | 含义 | 什么时候改 |
| --- | --- | --- |
| `待读` | 建了笔记但还没读 | — |
| `在读` | 正在读 | 读第一遍时 |
| `精读` | 三遍读完，5 个问题都答了 | 答完第 5 问 |
| `已复现` | 代码/实验跑通过 | 复现记录写进 03_输出 |

`rating` 1–5：**只问一件事 —— 它对我现在的研究有用吗**（不是"论文好不好"）。

## 最重要的两条

1. **笔记里不许出现大段原文抄写**。摘录可以有，但必须附页码，且不超过 3 条。
2. **第 5 问（和我研究的关系）写不出来 = 这篇白读了。** 宁可写"暂时看不出关系，但它解决 X 的手法可能迁移到 Y"。
