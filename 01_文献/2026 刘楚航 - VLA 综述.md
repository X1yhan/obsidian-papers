## 1. 它的分类轴（综述最重要的一件事）

作者把领域切成四层，**这就是这张地图的骨架**：

```
1. 基础层   1.1 单模态基础模型（感知/认知）
           1.2 多模态模型（跨模态融合）
           1.3 从 VLM 到动作生成     ← 关键的"翻译"环节
           1.4 能力权衡三角          ← 待读原文确认：三个角是哪三个？
2. 架构层   2.1 Transformer 端到端（2.1.1 经典 Transformer / 2.1.2 基于预训练 VLM）
           2.2 动作专家的分层式架构  ← 大模型出"意图"，小策略出"关节角"
           2.3 世界模型的预测式架构  ← 先想象后果再动
3. 数据层   3.1 经典数据集  3.2 基准与仿真器  3.3 对比表
4. 问题层   4.1 跨模态数据对齐  4.2 高效学习与训练资源  4.3 长时序任务
```

**一句话记住三种架构**：端到端（一个网从像素到动作）、分层（大脑 + 小脑）、世界模型（先预测再决策）。
